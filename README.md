## Getting Started

To run this project locally, make sure Flutter is installed.

1. Clone the repository:

   ```bash
   git clone https://github.com/birendrakalauni/birendra-kalauni.github.io.git
   ```

2. Navigate to the project directory:

   ```bash
   cd birendra-kalauni.github.io
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run -d chrome
   ```

## Build for Web

```bash
flutter build web
```

The generated website files will be available in `build/web/`.
